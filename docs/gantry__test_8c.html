Detailed Description

Boot, diagnostics, and run-mode dispatch for the cup-stacking gantry.

On boot: checks SPI comms to the three drivers, homes X and Y into their REFL switches, and takes the current Z position as zero (crank the bed to its bottom before power-on). It then presents a menu over USART2 (reached through the Black Pill USB-UART bridge):

  • 'u' : enter User mode (teleop) (WASD/KL jog, space toggles vacuum); never returns.
  • '2' : run one automatic pick-and-stack, then return to the menu.
Vacuum
HW-039 / BTS7960 driven by PWM on PA8 = TIM1_CH1. R_EN/L_EN are tied high and LPWM grounded in hardware; duty is clamped to a hard ceiling and soft-ramped.
Diagnostics
g_test carries reset_cause and the pre-home REFL snapshots (x_stopL_prehome / y_stopL_prehome) for field debugging.
