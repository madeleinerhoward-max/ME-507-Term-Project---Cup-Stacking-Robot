◆ tmc5160_home()

tmc_result_t tmc5160_home ( TMC5160_t * drv)

Home an axis into its REFL endstop and set machine zero.

Clears stale stop state, drives in the negative direction, and accepts the stop only after it is active for TMC_STOP_DEBOUNCE consecutive reads (rejecting noise glitches). Then zeroes at the switch, backs off TMC_HOME_BACKOFF_MM, and re-zeroes.

Parameters
drvDriver instance. Do not call on Z (no endstop).
Return values
TMC_OKHomed successfully.
TMC_TIMEOUTSwitch never tripped within TMC_HOME_TIMEOUT_MS.

void tmc5160_init ( TMC5160_t * drv)

Initialise a driver for SpreadCycle positioning mode.

Clears faults, configures the chopper, applies irun / ihold, loads conservative ramp parameters, selects positioning mode with stops disabled, and zeroes XACTUAL/XTARGET.

drvDriver instance.
