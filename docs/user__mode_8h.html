Detailed Description

Interactive teleop over USART2: keyboard jog and vacuum control.

Keystrokes arrive on USART2 (115200 8N1) from a Black Pill USB-UART bridge running a PuTTY session on the PC. Jogs are non-blocking: each keypress updates a commanded position and the TMC ramp generator runs the motion.

Controls
  • W / S : Y axis + / - (top rail)
  • A / D : X axis - / + (suction-cup carriage)
  • K / L : Z bed down / up
  • space : toggle the vacuum (soft-ramped)
