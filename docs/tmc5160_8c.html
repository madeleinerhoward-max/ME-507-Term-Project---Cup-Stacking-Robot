Detailed Description

TMC5160 SPI driver implementation (see tmc5160.h for the API).

SPI datagram (datasheet section 5): 40 bits, MSB first, Mode 3.

  • TX byte 0 = address; bit 7 = 1 for write, 0 for read.
  • TX bytes 1..4 = data, MSB first.
  • RX byte 0 = SPI status.
  • RX bytes 1..4 = data from the PREVIOUS datagram, so a read needs two transfers and the value lands on the second.
